## 📖 About the Project

This repository contains 40 Python scripts, each solving a small, well-defined problem. The exercises are grouped into several categories:

| Category | Description |
|----------|-------------|
| 🔁 **Loops & Iteration** | `while` and `for` loops, number ranges, patterns |
| ➗ **Conditionals** | `if-else` logic, leap years, largest among three |
| 🔢 **Numbers & Math** | Factorials, reversing digits, sum of digits, divisors |
| 🔡 **Strings** | Vowels/consonants counting, reversing without slicing, word counting |
| 📊 **Lists** | Max/min from a list, filtering evens/odds, sum/average |
| 📖 **Dictionaries** | Student name–marks mapping |
| 🖨️ **Pattern Printing** | Star and number patterns |

The exercises start with very simple tasks (printing numbers) and gradually introduce more complex operations like string manipulation and data structures. This progression is designed to help learners build confidence as they advance.
